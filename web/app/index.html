receiver

An unofficial Signal client that runs entirely in your browser and reaches Signal only through Tor. It is not usable yet: linking a device is still being built.

Starting…

    What this page does today

    It starts a Tor client inside this tab and connects to the Tor network through a Snowflake bridge. Through Tor it opens Signal's device-linking connection, with TLS that trusts only Signal's own certificate authority. Signal answers with a one-time provisioning address, the first step before a link QR code can be shown. The address is not displayed, and the connection is closed right away. Nothing is linked and no account is touched.

    Signal sees a Tor exit, not your IP address. The Snowflake bridge sees your IP address, not where your traffic goes.

    Like every web app, this code is delivered by this site each time you open it. Read it before you trust it.
